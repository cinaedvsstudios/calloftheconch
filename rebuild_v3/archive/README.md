# Archive

This folder contains retired source files kept for reference after their active `res://` references were removed.

Rules:

- Nothing in `archive/` should be referenced by active scenes or scripts.
- Compatibility alias scenes may remain at old paths when removing them would break external editor references.
- Files are archived only when their active replacement is established.
- Do not drag archived scenes into production levels.
