# Sea of Pillars

First playable sea and current development region.

## Levels

- `levels/sea_of_pillars_prototype.tscn`: current working test level and default title-screen selection.
- `levels/sea_of_pillars_main.tscn`: production work version selected from the title screen.
- `levels/neresithoppos_city.tscn`: current City of Pillars scene.
- `levels/pirate_ship_interior.tscn`: prepared empty area for the next interior build.
- `levels/scylla_boss_arena.tscn`: prepared empty area for the first boss build.

Local reusable content belongs in `objects`, `enemies`, `bosses`, `effects` and `background_scenery`. Shared content belongs in `game/shared`.
