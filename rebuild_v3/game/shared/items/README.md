# Shared Items and Shells

Each shell owns its reusable presentation and projectile scenes here. The gameplay item controller selects them from equipped item data; levels do not own shell behaviour.

Current folders:

- `normal_conch`: existing shared conch pulse route
- `charonia_tritonis`: Super Conch pulse profile
- `terebridae`: drill pulse profile
- `conus_textile`: dart and tether scene
- `murex_pecten`: Purple Shield scene
- `tridacna_gigas`: Surge scene
- `haliotis`: camouflage presentation
- `argonauta`: ink projectile and paralysis cloud scenes
- `crown_sea_grapes`: Greatfin transformation effect
- `tyche_margarites`: passive treasure system, not yet implemented

Do not copy these scenes into individual sea folders. They are carried by Hylas between levels.
