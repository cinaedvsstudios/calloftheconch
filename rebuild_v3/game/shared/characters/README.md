# Shared Characters

This folder contains the character scenes used across seas.

- `hylas_normal/hylas_normal.tscn`: the playable Hylas scene.
- `hylas_greatfin/README.md`: Greatfin uses the same playable Hylas scene and swaps its SpriteFrames at runtime.
- `school_of_fish/school_of_fish.tscn`: reusable ambient fish school.
- `whale/README.md`: whale travel and checkpoint character references.
- `leaf_sheep/README.md`: reserved for the completed Leaf Sheep companion scene.

Do not place a second Hylas instance into a level that already includes Hylas.
