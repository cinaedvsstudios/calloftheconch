# Landscape scenes

This folder contains drag-ready landscape scenes with collision generated from each source texture's alpha channel.

## Collision behaviour

- Pixels with alpha below `0.12` are treated as transparent and receive no collision.
- Visible regions are traced into `CollisionPolygon2D` shapes and simplified to avoid thousands of jagged points.
- Tiny detached alpha flecks below 64 square pixels are ignored.
- Large textures are traced at a maximum dimension of 2048 pixels, then scaled back to the source size.
- Polygon results are cached per texture while the project is running or open in the editor.

Each scene uses the shared `alpha_collision_landscape_base.tscn`. Drag the individual `.tscn` into a level and move, rotate or scale the root normally; its sprite and collision remain aligned.

## Included scenes

- `rock02.tscn` through `rock15.tscn`
- `rock_corner.tscn`
- `island00.tscn` through `island03.tscn`
- `spike_rock.tscn`
- `sand01.tscn` and `sand02.tscn`
- `beach.tscn`

`island02.tscn` points to the existing source file `assets/backgrounds/lsland02.webp`; the source filename contains an old lowercase-L typo and was not renamed to avoid breaking existing level references.

To inspect the generated polygons, open a landscape scene in Godot and enable visible collision shapes. The collisions are generated by the tool script and are not duplicate image assets.
