# Shared Enemies and Hazards

Drag these scenes directly into a level:

- `shark_enforcer.tscn`
- `jellyfish.tscn`
- `black_bloom.tscn`
- `depth_spark_plant.tscn` — stationary dark-depth plant; frames 01–03 loop normally, frame 04 discharges damaging pink/orange/red sparks every 18 seconds.

Sea-specific enemies should be added to that sea's folder once their scene is complete.
